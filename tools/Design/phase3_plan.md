# 第三阶段扩展方案

原计划六项不变：黄金事件、钻头里程碑、地表加工厂、研究所、挑战深井、星系跃迁和星座图。
本方案是参考同类增量游戏后加入的内容和新顺序。标“新”的是新增项。

## 开发顺序

| 步 | 内容 | 来源 | 给玩家带来什么 |
|---|---|---|---|
| 0 | 新：欢迎回来结算屏 | 增量游戏通行做法 | 替换现在的一行离线提示，列出离线时挖了多深、赚了多少、拿到什么 |
| 0 | 新：重铸收益预估 | Clicker Heroes 等 | 显示“现在重铸得多少”和“每分钟增长”，玩家能判断时机 |
| 0 | 新：节奏模拟工具 | 自有需要 | 无界面跑完整局，核对首次重铸时间和每层耗时 |
| 1 | 黄金事件，加新：地核不稳 | Cookie Clicker 的金饼干和愤怒饼干 | 红色发光物，点了可能大赚也可能短暂减益，多一个冒险选择 |
| 2 | 钻头里程碑，加新：岩层精通 | Melvor Idle 的精通 | 每层累计挖掘量升精通等级，给该层永久小加成，旧地层仍有挖的理由 |
| 3 | 新：重铸里程碑 | Antimatter Dimensions 的 Eternity 里程碑 | 第 1/3/5/10/25 次重铸后，开局自带钻头、技能和自动功能，重开不再重复劳动 |
| 3 | 新：自动化规则面板 | Antimatter Dimensions 的自动购买器 | 设定优先买什么、保留多少钱、到多深自动重铸 |
| 4 | 新：钻探流派 | Realm Grinder 的阵营 | 每次重铸选一派，如爆破派、机群派、精工派、富矿派，玩法和技能权重不同；每派通关一次得永久奖励 |
| 5 | 地表加工厂，加新：地心结晶 | Cookie Clicker 的糖块 | 按真实时间慢慢生长的稀有资源，用于升级工厂或缩短研究，给玩家每天回来看看的理由 |
| 6 | 研究所，加新：探险队 | Mr. Mine 的科学家和挖掘 | 遗迹房间里救出探险员，派去探索，分四档风险，失败率越高奖励越好，离线也在跑 |
| 7 | 挑战深井 | Antimatter Dimensions 的挑战 | 不变 |
| 8 | 星系跃迁和星座图，加新：行星规则 | Realm Grinder 的多层重置 | 作为第二层重置，每颗行星改一条规则，如低重力、满地岩浆、矿物翻倍但硬度翻倍 |

## 明确不做

- 矿物股市：系统重，和挖掘主线关系弱，Cookie Clicker 里也是偏后期的支线。
- 广告换加倍和任何付费加速：这是单机买断思路的游戏，结晶只能靠时间获得。
- 强制重铸：选择权留给玩家，靠收益预估解决“不知道何时重铸”。

## 依据的可靠程度

搜到的资料大多是维基、社区帖和攻略，具体数值不能当真，所以这里只借机制，数值由节奏模拟定。
Melvor 精通和 Clicker Heroes 的重铸判断来自我自己的了解，这次搜索没有直接证实。
